⚔️ HW Lite Inspector

About the script

Deep stats analysis mod for Hero Wars. Reveals hidden values, calculates reductions via Damage Matrix, and allows stat adjustments.

Features

  • Reveals hidden stats of enemies.
  • Damage Matrix: calculates physical and magical reductions between heroes.
  • Calculator: allows manual stat adjustments to test outcomes.
  • Parses Match History & Journal.
  • Export battles in text format.

Installation

1. Install a userscript manager like Tampermonkey for your browser.
