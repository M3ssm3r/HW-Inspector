Frequently Asked Questions

Answers to common inquiries regarding the addon's operations and safety.

Is it safe to run? +

Yes, absolutely. The addon runs entirely within client memory, and does not alter network packages. It only displays network data packets already processed by your browser.

Does it modify any gameplay actions? +

No. This tool does not perform scripts automation, auto-fights, hacks, or macro interactions. It remains entirely passive.

Can this lead to profile restrictions? +

No user profiles have experienced safety issues since this script operates like a standard browser inspect tool window without network manipulation.
