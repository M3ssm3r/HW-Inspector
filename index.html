Features

Deep Stats

Reveals hidden values and full hero attributes in Lobby and Battles.

Damage Matrix

Calculates exact physical and magical damage reductions between heroes.

Calculator

Adjust Armor, Magic Resist, and Penetration on the fly to see how it affects damage.

How to Install

  1. Install a userscript manager like Tampermonkey.
  2. Click the "Install Script" button above.
  3. Confirm the installation in the Tampermonkey tab.
  4. Refresh your Hero Wars game page!
